# P19 — Real-World Dogfood

Dependencies: P18  
Owned paths: tests/real-dogfood, packages/dogfood-live, docs/evidence/production-connectivity/dogfood  
Uses a real repository as the first complete proving ground

## Goal

Prove the flagship journey against real external systems — the point where
"persistent Spirit, replaceable bodies" becomes demonstrably real.

## Acceptance journey (literal)

User gives mission → SOS understands repository → SOS creates/revises architecture
hypothesis → SOS proposes candidate → assurance gate → SOS creates durable work graph →
SOS summons cloud body → body works while user's computer is OFF → independent evaluation →
repair/retry/ASK where necessary → PR → deployment → runtime observation →
mission verification → package learning.

## Acceptance

The journey completes against real external systems with exact revisions recorded at every
stage; reproducibility evidence exists (a second run on a fresh repository); honest states
and unresolved uncertainty remain visible.

## Completion

Branch + independent architect gate + PR + CI + squash-merge + machine-state reconcile.
