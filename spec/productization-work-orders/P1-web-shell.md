# P1 — Production Web Console Shell

Dependencies: P0
Owned paths: apps/web, packages/web-contracts
Worker: A

Goal:
Create the production Next.js web console using the ShareNet-inspired interaction hierarchy while reusing @sos-2/ui-contracts.

Acceptance:
- desktop left rail
- mobile bottom nav
- sparse warm-light design
- current-state hero
- next allowed action
- responsive cards/timelines/topology/details
- loading, empty, unknown, unavailable and error states
- accessible keyboard navigation
- rationale deep-links
- no duplicated SOS domain semantics

A fresh user must reach Mission, System, Changes, Evidence, Experiments, Packages, History and ASK without knowing internal package names.
