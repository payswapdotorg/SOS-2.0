# P1 — Production Web Console Shell

Dependencies: P0  
Owned paths: apps/web/shell, packages/web-contracts/core  
Worker: A in wave 1

## Goal

Create the production Next.js console using the ShareNet-inspired interaction hierarchy while exposing live Spirit/Body/Observation state without leaking internal architecture vocabulary.

## Acceptance

- desktop left rail and mobile bottom navigation
- dominant current mission/system-state hero
- current shortfall/opportunity and next allowed action
- active tasks, body leases and observation status
- sparse warm-light design
- responsive cards/timelines/topology/details
- loading, empty, unknown, unavailable, partial and error states
- keyboard/accessibility support
- rationale deep-links
- no duplicated SOS domain semantics
- clear DEMO/SIMULATED labeling where fixtures are shown

A fresh user can find Mission, System, Changes, Evidence, Experiments, Packages, History, ASK and active autonomous work without knowing package names.
