# SOS 2.0 — Software Evolution Operating System

SOS 2.0 is a mission-governed control plane for continuously improving software systems.

Mission:
Make software exponentially better over time while making software systems increasingly easy for humans to reason about.

The W0-W18 core implementation program is COMPLETE and frozen.
The repository is now in the post-W18 productization program, which turns the proven core into a production experience and an autonomous execution fabric.

Core semantic loop:
Constitution -> Mission -> Value -> Context -> System State -> Evidence -> Hypothesis -> Candidate -> Assurance -> Experiment -> Decision -> Promotion/Rollback -> Learning -> Package -> Meta-Evolution

## Product thesis

SOS is the persistent **Spirit**. Reasoning models are replaceable mechanisms. Harnesses/bodies are replaceable execution mechanisms.

The target product can continuously observe a software system without a permanent coding agent, then summon an appropriate body only when active inspection, implementation, deployment, remediation or another consequential operation is required.

The flagship greenfield journey is:
Mission -> GitHub repo -> architecture/candidate -> governed worker tasks -> temporary body -> implementation -> independent evaluation -> GitHub/deployment -> evidence-backed completion.

The user's computer is optional for cloud/remote work.
