# ShareNet-Inspired SOS Product Design

Reference source: pectoraux/ShareNet
Reference product: https://sharenet-conformance.vercel.app

## Patterns to adapt

- desktop left navigation
- mobile compact header plus bottom navigation
- sparse warm-light visual system
- strong current-state hero
- restrained semantic status colors
- progressive disclosure
- loading/error/empty/unknown state blocks
- topology/path visualization where relationships matter
- concise content hierarchy

## Status semantics

green = healthy/validated/satisfied
amber = degraded/recovering/attention
red = blocked/failure/rollback
neutral = inactive
separate unknown/epistemic treatment for uncertainty

Never use color as the only semantic channel.

## What not to copy

Do not copy ShareNet brand identity, labels, iconography or domain meaning. The reference is interaction hierarchy and information density.
