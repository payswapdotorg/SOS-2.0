# Testing and Evidence Strategy

Layer 1: semantic schemas, identity, state transitions and invariants.
Layer 2: unit, contract and property tests.
Layer 3: architecture conformance and executable fitness constraints.
Layer 4: integration behavior.
Layer 5: end-to-end mission scenarios.
Layer 6: replay, simulation, shadow, canary, experiment and rollback.
Layer 7: adversarial fault injection and truth-state failures.
Layer 8: meta-tests of SOS self-improvement.

Every layer produces machine-readable evidence linked to exact revisions.
Testing is evidence, but tests are not the whole Evidence Graph.
