# Tech Lead Checklist

Before dispatch:
- live main inspected
- machine state reconciled
- dependencies proven merged
- Work Order read
- path ownership confirmed
- architecture authority identified
- acceptance criteria testable
- evidence requirements known

Before approval:
- exact base SHA
- exact head SHA
- actual diff inspected
- Architecture Delta present
- tests on exact head
- evidence provenance valid
- no duplicate authority
- no autonomy escalation
- rollback impact reviewed
- causal/package impact reviewed

After merge:
- actual merge verified
- state reconciled
- frontier recomputed
- next three independent Work Orders identified
